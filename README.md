# AS Mega Mall - Free Android App Project

এই প্রজেক্টটি AS Mega Mall-এর জন্য একটি free native Android WebView app starter।

## এতে আছে
- AS Mega Mall logo
- Home page
- Product categories
- Search
- Cart
- WhatsApp order
- Phone call
- Email
- Bangladesh-wide home delivery message
- Dhaka, Bangladesh contact information

## গুরুত্বপূর্ণ
এই ZIP-এর source project থেকে APK বানাতে Android Studio + Android SDK প্রয়োজন।
Android Studio-তে project folder খুলে:
Build > Build App Bundle(s) / APK(s) > Build APK(s)

## পণ্য পরিবর্তন
`app/src/main/assets/index.html` ফাইলে `products` তালিকায় নাম ও দাম পরিবর্তন করুন।
