🛍️ AS Mega Mall - Free Android App Project

📦 Change Products

অ্যাপের পণ্য, নাম ও দাম পরিবর্তন করতে নিচের ফাইলটি Edit করুন:

"app/src/main/assets/index.html"

এই ফাইলের "products" তালিকায় পণ্যের:

- Product Name
- Price
- Category
- Image
- Description

পরিবর্তন করা যাবে।

🛠️ Build APK

এই Source Project থেকে APK তৈরি করতে প্রয়োজন:

- Android Studio
- Android SDK
- JDK

APK তৈরির ধাপ

1. Android Studio Open করুন
2. Open নির্বাচন করুন
3. এই Project Folder নির্বাচন করুন
4. Gradle Sync সম্পূর্ণ হওয়া পর্যন্ত অপেক্ষা করুন
5. উপরের Menu থেকে:

Build → Build App Bundle(s) / APK(s) → Build APK(s)

APK তৈরি হলে Android Studio থেকে APK-এর Location দেখাবে।
